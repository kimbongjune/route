- [x] 최소요금 옵션. 요금은 입구·출구 쌍에 붙어 링크 가중치로 넣을 수 없고 카카오내비·구글·HERE도 후보 경로의 통행료를 보여 주는 방식이라, `POST /routes`가 최소시간·최단거리·무료도로 후보를 통행료와 함께 주고 화면의 비교 목록에서 고르며 가장 빠름·가장 짧음·최소 요금을 표시하는 것으로 2026-10-25에 정하였다. 13 문서

## 17. 지오코더(M5)

주소 검색은 도로명주소 전자지도 건물 레이어(도로명+건물번호, 읍면동+지번, 건물명)로, 장소 검색은 국가관심지점정보 POI(명칭과 별칭)로 하며 상가정보는 POI에 포함되어 있어 넣지 않기로 2026-10-24에 정하였다. 색인은 routedb와 같이 임포터가 파일로 만들고 `api`가 기동 시 읽으며 PostGIS는 10단계와 함께 2차이다. 지오코딩·역지오코딩을 모두 로컬 서버에서 처리한다.

- [x] 국가관심지점정보 전국 16개 시도 다운로드(0단계)
- [x] 전자지도 건물·도로구간·행정경계와 POI 4개 테이블의 필드 확인, EPSG:5179→WGS84 변환 확인. 변환 결과가 브이월드 좌표와 소수 6자리까지 같다. 13 문서
- [x] 검색 색인 파일 설계와 임포터 구현. `routedb-geocode` 크레이트와 `importer-geocode`가 `geocode.idx`(1.62GB, 주소 6,412,939, 장소 9,813,303, 별칭 4,733,996)를 110초에 만든다. 장소는 2-gram 색인으로 부분 문자열을 찾고 주소는 정렬 배열의 이분 탐색이며 공간 격자는 넣지 않았다. 13 문서
- [x] `api` 주소 검색, 장소 검색, 역지오코딩(좌표→주소) 구현. `/geocode`가 주소와 장소를 함께 주고 지도 중심을 받으며 `/reverse`를 더하였다. 프론트는 검색에 지도 중심을 보내고 클릭·끌기 지점의 이름을 주소로 바꾼다. 13 문서
- [x] 브이월드 검색 결과와 샘플 비교 후 브이월드 검색 의존 제거. 주소·장소 40개 비교(주소 18건 중 200m 안 15건, 장소 20건 중 11건) 뒤 브이월드 검색 호출을 제거하였고 브이월드는 타일 프록시에만 남는다. 13 문서

## 18. routedb 서버 모드(M6)

내비는 `nav-api`가 routedb를 같은 프로세스의 라이브러리로 호출하여 완결되므로 서버 모드(프로토콜 서버, `client-rs`, JDBC, 내비 전환)는 하지 않기로 2026-10-25에 정하였다. routedb를 다른 프로그램에서 따로 호출할 일이 생기면 그때 다시 검토한다.

## 19. 골목(2차)

골목 일방통행의 방향을 전국 단위로 주는 공개 데이터가 없어(06 문서 "구축대상 도로와 골목") 1차는 골목 없이 표준노드링크 링크에서 경로를 끝내고 "목적지 부근"으로 안내하기로 2026-10-24에 정하였다. 2026-10-24에 국가교통DB 도로망, 일방통행 지정 고시, 택시·DTG 궤적, 지자체 교통안전표지 데이터, 정밀도로지도 확대 계획을 추가로 확인하였으나 골목 방향은 없었다. 양방통행 골목만 넣는 방법은 도로중심선과 표준노드링크의 연결, 제한속도·통행 금지 가정값, 일방통행 골목이 빠진 구역의 경로 품질이 문제이므로 한 구역에서 실험한 뒤 전국 확대 여부를 정한다.

- [ ] 경찰청·도로교통공단에 TMACS(교통안전정보관리시스템) 일방통행 규제 데이터 제공 가능 여부 문의
- [ ] 용산구 한 곳에서 연속수치지형도 도로중심선의 양방통행(`ONSD` ITH002) 골목을 표준노드링크 교차로에 연결하는 실험. 연결 오류율과 경로 품질을 확인한다
- [ ] 실험 결과로 전국 확대 여부 결정. 일방통행 골목(ITH001)은 방향 데이터가 생길 때까지 넣지 않는다

## 2차에 검토할 데이터

VSL 가변속도제한 API 신청, 상습 결빙구간(`maps/주의운전/행정안전부_상습 결빙구간.csv`)과 안개취약 구간과 주의운전구간 실시간 메시지, 휴게소와 하이패스 차로, 정밀도로지도의 과속방지턱 레이어가 행안부 데이터를 보완할 수 있는지를 2차에 검토한다.

UTIC 도로위험상황예보(`getRoadAccJson.do`)는 실시간 위험 구간 경고에, 교통안전(`tsdmsOpenData.do`)은 사고다발 경고 보강에, 공사정보(`tcsOpenData.do`)는 공사 구간 반영에 사용할 수 있는지 2차에 검토한다.
