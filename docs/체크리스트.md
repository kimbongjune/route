## 2차에 검토할 데이터

VSL 가변속도제한 API 신청, 상습 결빙구간(`maps/주의운전/행정안전부_상습 결빙구간.csv`)과 안개취약 구간과 주의운전구간 실시간 메시지, 휴게소와 하이패스 차로, 정밀도로지도의 과속방지턱 레이어가 행안부 데이터를 보완할 수 있는지를 2차에 검토한다.

UTIC 도로위험상황예보(`getRoadAccJson.do`)는 실시간 위험 구간 경고에, 교통안전(`tsdmsOpenData.do`)은 사고다발 경고 보강에, 공사정보(`tcsOpenData.do`)는 공사 구간 반영에 사용할 수 있는지 2차에 검토한다.
