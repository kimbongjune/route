## 8. 내비 API 임베디드(M3)

- [x] `nav/api`에 routedb-core를 링크하고 `RouteDb`를 `Arc`로 공유한다. handler·service·model과 `state.rs`, `error.rs`, `lib.rs`의 `app()`, `tests/` 통합 테스트 구조이며 탐색은 `spawn_blocking`에서 실행한다. 13 문서

- [x] 사고다발 폴리곤 R-tree와 경로 교차 체크. 유형별 최신 배치 5,026건을 `build_polygons.py`로 모아 `AccidentIndex`의 R-tree에 넣고, 경로 선분과 교차하는 폴리곤을 같은 유형의 연속 구간으로 합쳐 `accident_sections`로 응답한다. 서울역→강남역은 29구간이다. 8, 13 문서
- [x] 응답 JSON에 안내문과 경고 포함. 교차로 이름 `NODE_NAME`을 그래프 파일 버전 11에 넣고 `instructions`에 "남영역앞교차로에서 좌회전, 한강대로77길" 같은 문장을, `warnings`에 카메라·방지턱·사고다발 구간·요금소·통과제한을 거리 순서로 넣는다. 13 문서

## 2차에 검토할 데이터

VSL 가변속도제한 API 신청, 상습 결빙구간(`maps/주의운전/행정안전부_상습 결빙구간.csv`)과 안개취약 구간과 주의운전구간 실시간 메시지, 휴게소와 하이패스 차로, 정밀도로지도의 과속방지턱 레이어가 행안부 데이터를 보완할 수 있는지를 2차에 검토한다.

UTIC 도로위험상황예보(`getRoadAccJson.do`)는 실시간 위험 구간 경고에, 교통안전(`tsdmsOpenData.do`)은 사고다발 경고 보강에, 공사정보(`tcsOpenData.do`)는 공사 구간 반영에 사용할 수 있는지 2차에 검토한다.
