# 10. 노인·장애인보호구역과 경찰청 보호구역 API

어린이보호구역 표준데이터는 시설 중심점만 있고 구역 범위, 제한속도, 시간제가 없어 보완 후보 두 가지를 확인하였다. 수치는 `scripts/zone/stats.py`로 집계하였다.

## 노인·장애인보호구역 표준데이터

`maps/전국노인장애인보호구역표준데이터/전국노인장애인보호구역표준데이터.csv`이며 정의는 공공데이터 제공 표준 20차 264~265쪽에 있다. 제공범위는 지방경찰청장이 지정·운영하는 노인·장애인 생활보호구역이며 갱신주기는 반기이다.

4,184건, CP949, 위경도 WGS84이며 컬럼은 `장소유형코드`, `대상시설명`, `시도명`, `시군구명`, `시군구코드`, `소재지도로명주소`, `소재지지번주소`, `위도`, `경도`, `제한속도`, `관리기관명`, `관리기관전화번호`, `관할경찰서명`, `CCTV설치여부`, `CCTV설치대수`, `보호구역도로폭`, `데이터기준일자`, `제공기관코드`, `제공기관명`이다.

`장소유형코드`는 01 노인보호구역, 02 장애인보호구역이며 `1` 3,364 · `01` 554 · `2` 218 · `02` 48로 앞자리 0이 섞여 있어 0을 제거해 정규화하였다. 어린이보호구역 CSV에는 없는 `제한속도` 컬럼이 있으며 30이 3,809, 60이 155, 50이 121, 40이 67, 0이 25, 20이 4, 70이 1, `3050`이 2건이라 0과 `3050`은 정리가 필요하다. 위경도는 보호구역의 중심이고 표준의 대상시설명 설명이 "주변 300m를 보호구역으로 지정하기 위해 선정한 시설"이라 이 보호구역이 시설 중심 반경 300m로 정의된다는 근거가 문서에 있다. 시간제 필드는 없으며 도로명주소 167건, 지번주소 610건, `CCTV설치대수` 2,318건, `보호구역도로폭` 1,881건이 빈값이다.

## 경찰청 전국 보호구역 현황 API

공공데이터포털 15142010(`https://www.data.go.kr/data/15142010/openapi.do`)이며 어린이·노인·장애인 보호구역을 geometry와 함께 제공하는 REST JSON API로 수정일은 2025-11-18이다. 경찰청 도시교통정보센터의 이전 보호구역 정보는 2025-01-06 이후 갱신이 중단되었고 공공데이터포털로 일원화되었다는 안내가 있어, 이전에 후보로 검토한 전국 보호구역정보 15118616은 대상에서 제외하였다.

- 엔드포인트는 `https://apis.data.go.kr/1320000/safetyzonedtlinfo/getdtllist`이다.
- 요청 파라미터는 `serviceKey`(필수), `sggCd` 시군구코드(필수), `numOfRows`, `pageNo`, `callDate` 변경기준일자, `assignType`(1 우선지정대상, 2 지정대상), `emdongCd`, `rprsPtznMngNo`이며 설명 이미지 하단에 더 있을 수 있다.
- 응답 필드는 `fturGeomVl` 형상, `ptznMngNo` 보호구역관리번호, `pjtNo`, `trgtFcltNm` 대상시설명, `fcltTypeCd`(1 어린이, 2 노인, 3 장애인), `rprsPtznMngNo`, `useYn`, `stdgCd`, `roadNmAddr`, `roadNmDaddr`, `lotnoAddr`, `lotnoDaddr`, `sggCd`, `emdongCd`, `assignType`, `frstRegDt`, `lastMdfcnDt`, `fcltDtlTypeCd`이다. 헤더는 `resultCode`, `resultMsg`, 본문은 `pageNo`, `numOfRows`, `totalCount`, `totalPages`, `items.item[]`이다.
- 제한속도·시간제 필드는 응답에 없으며 이 API에서 얻는 것은 구역 범위이다. 속도는 노인·장애인 CSV와 노드링크 `MAX_SPD`에 의존한다.
- 일일 호출 한도가 300건이고 시군구마다 별도로 호출해야 하므로 시군구 약 250개와 페이지 수에 따라 수일이 걸릴 수 있다. `numOfRows` 최댓값은 확인하지 못하였다.
- 활용신청은 완료하였고 승인 대기 중이다. 키는 `.env`의 `DATA_GO_KR_API_KEY`이며 승인 전 호출 결과는 `403 SERVICE_KEY_IS_NOT_REGISTERED_ERROR`였다.
- `fturGeomVl`이 점·선·면 중 무엇인지와 좌표계는 호출해서 확인해야 한다.

## 보류한 결정

어린이보호구역 표준데이터를 계속 사용할지는 이 API의 geometry와 비교한 뒤 결정하기로 하였다. 스쿨존 제한속도·시간제 데이터는 아직 확보하지 못하였으며 시간제 속도제한은 2026년 8월 보도 기준 84곳이 운영 중이고 연말까지 약 160곳을 추가할 계획이라고 하나 시설 목록은 확인하지 못하였다.
