# 내비게이션 기획

무엇을, 왜, 어디까지 만드는지 정리하였다. 어떻게 만드는지는 [내비게이션 설계](02-내비게이션-설계.md)에 있다.

## 목표와 대상

일반 승용차 운전자를 대상으로 한국 도로망 기준으로 동작하는 웹 GPS 내비게이션을 개인 프로젝트 규모로 만든다. 카카오내비, 티맵의 주요 기능을 국가 공개데이터만으로 구현하는 것이 목표이며 사용자 주행 궤적 같은 프로브 데이터와 정밀지도는 없다는 전제이다. 플랫폼은 웹(데스크톱과 모바일 브라우저)이고 대상 차량은 승용차이며 높이·중량·차종 제한은 데이터가 있어 지원하고 차폭·차장 정밀 라우팅은 제외한다. 경로 엔진은 별도 프로젝트인 routedb를 사용하며 그 첫 클라이언트이다.

## 원칙

- OSM을 사용하지 않고 도로망, 지도, 안전정보 모두 국가·공공기관 공개데이터로 구성한다.
- 특정 지자체에만 동작하는 기능은 만들지 않으며 전국 커버가 기본이다.
- 외부 실시간 의존을 최소화하며 지도는 미리 적재해 직접 운영하는 서버에서 제공한다.
- 처음부터 과설계하지 않고 서버 한 대에서 전체가 동작하는 것을 먼저 목표로 한다.

## 경로 옵션

알고리즘은 하나로 고정하고 가중치 정의를 바꿔서 옵션을 만든다. 예상소요시간은 별도 계산이 아니라 최소시간 경로의 가중치 합 그 자체이다.

| 옵션 | 가중치 | 단계 | 비고 |
|---|---|---|---|
| 최소시간 | 거리 ÷ 제한속도 × 실시간 배율 × 돌발 배율 | 1차, 기본 | |
| 무료도로 우선 | 소요시간 + 유료도로 링크 페널티 | 1차 | 유료도로 링크 목록은 [12. 유료도로](12-유료도로-데이터.md)에서 만들었다 |
| 최단거리 | 거리 | 내부용 | 테스트와 검증 기준 |
| 최소요금 | 통행료, 영업소 쌍 단위 | 2차 | 링크 단위가 아니라 영업소 쌍 단위의 별도 모델링이 필요하다 |
| 대안경로 | 최적 경로의 주요 링크에 페널티를 주고 재탐색 | 2차 | 새 데이터가 필요 없다 |

## 안전 정보 안내

일반 내비와 같은 수준으로 실시간 예측이 아니라 미리 저장한 데이터로 경고한다. 과속카메라는 점 안내이며 구간단속은 시작·종료 쌍으로 구간 안내한다. 과속방지턱은 점 안내이며 지자체 등록 편차가 있어 누락 가능성을 감수한다. 사고다발지역은 경로가 폴리곤을 통과하면 사망사고 건수를 포함해 경고한다. 스쿨존은 알림과 함께 해당 구간의 제한속도 30km/h를 경로 계산에 반영하며 1차는 24시간 30km/h로 단순화한다. 시간제는 2026년 기준 전국 약 1만 5천 곳 중 84곳이지만 확대 중이다.

## 지도 화면

배경지도와 건물은 모두 직접 운영하는 지도서버에 미리 적재해 제공하며 브이월드 타일은 사용하지 않는다. 1차는 회전을 포함한 2D이며 주행 중에는 진행방향이 위이다. 2차에 2.5D를 켜면 두 손가락으로 쓸어올릴 때 같은 지도가 전환 효과 없이 연속으로 기울어지고 건물이 돌출되어 실제 모바일 내비의 시점 변경과 같아진다. 2차에는 운영자가 관리 페이지에서 원본 데이터를 갱신하면 타일과 도로망이 재생성되도록 한다.

## 제외 항목과 사유

| 항목 | 사유 |
|---|---|
| OSM 데이터 | 원칙상 미사용. 한국에서는 지역별 품질 편차가 크고 국가 데이터가 있다 |
| 서울 TOPIS, 경기 실시간 피드 | 국가교통정보센터가 통합 창구이고 링크 체계가 달라 매칭 비용이 크다. 운영 중 공백이 확인되면 재검토한다 |
| 대중교통, 주차장, 주유소 연계 | 차량 내비 본래 기능과 무관하다 |
| 기상특보 연동 | 이번 범위에서 불필요하다 |
| 실시간 블랙아이스 예측 | 공개 API가 없고 별도 ML 모델링 영역이다. 일반 내비처럼 저장된 사고다발 데이터로 경고하면 충분하다 |
| 차폭·차장 정밀 라우팅 | 표준노드링크에 폭 데이터가 없다. 정밀도로지도로 가능하지만 고속국도·일반국도만 커버하고 처리가 복잡하다. 카카오모빌리티도 높이·중량·차종까지만 지원한다 |
| 브이월드 3D Cesium | 주행 중 화면에는 무겁고 2.5D로 충분하다 |
| 지도 렌더링 엔진 직접 개발 | 수십만 줄 규모라 MapLibre를 사용한다 |

## 도보·자전거 확장

OSM 없이 진행하는 계획이며 로드맵에는 넣지 않고 기록만 하였다. routedb는 가중치가 있는 연결망이면 모두 다루므로 그래프를 모드별로 추가하는 방식으로 확장한다. 자전거는 행정안전부 전국 자전거길 표준데이터로 전국 커버가 가능하며 표준노드링크에서 자동차전용도로를 제외한 그래프에 자전거길 레이어를 추가한다. 도보 1단계는 표준노드링크를 고속도로와 자동차전용도로 제외, 일방통행 무시, 고정 속도로 도보 그래프에 재활용하며 전국이 커버되지만 공원이나 지름길은 반영되지 않는다. 도보 2단계는 국토지리정보원 수치지형도 1/5,000 전국판에서 보행로와 소로를 추출해 보행 네트워크를 구축하며 도엽 병합과 위상 정리가 필요한 큰 GIS 작업이다.

## 향후 확장

최소요금 옵션과 대안경로 2~3개, 스쿨존 시간제 속도제한, 2.5D와 지도 갱신 관리 페이지와 직접 구현한 지오코더, 도보·자전거를 순서대로 추가하며 정밀도로지도 기반 화물차 라우팅, 대중교통 연계, 블랙아이스 예측 모델은 장기 과제로 둔다.
