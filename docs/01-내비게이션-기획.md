# 내비게이션 — 기획

무엇을, 왜, 어디까지 만드는지를 정리한다. 어떻게 만드는지는 [내비게이션 — 설계](02-내비게이션-설계.md)에 있다.

## 목표와 대상

일반 승용차 운전자를 대상으로, 한국 도로망 기준으로 동작하는 웹 기반 GPS 내비게이션을 개인 프로젝트 규모로 만든다. 카카오내비·티맵의 핵심 기능을 국가 공개데이터만으로 재현하는 것이 목표다. 자체 프로브 데이터(사용자 주행 궤적)나 자체 정밀지도는 없다는 것을 전제로 한다.

- 플랫폼: 웹(데스크톱·모바일 브라우저)
- 대상 차량: 승용차. 높이·중량·차종 제한은 데이터가 있어 지원, 차폭·차장 정밀 라우팅은 제외
- 경로 엔진: routedb(별도 프로젝트)를 사용하는 첫 클라이언트

## 핵심 원칙

- **OSM을 쓰지 않는다.** 도로망·지도·안전정보 모두 국가·공공기관 공개데이터로 만든다.
- **특정 지자체에만 되는 기능은 만들지 않는다.** 전국 커버가 기본이다.
- **외부 실시간 의존을 최소화한다.** 지도는 미리 적재해 자체 서버에서 서빙한다.
- **처음부터 과설계하지 않는다.** 서버 한 대에서 전체가 도는 것을 먼저 목표로 한다.

## 경로 옵션

알고리즘은 하나로 고정하고 **가중치 정의를 바꿔서** 옵션을 만든다. 예상소요시간은 별도 계산이 아니라 최소시간 경로의 가중치 합 그 자체다.

| 옵션 | 가중치 | 단계 | 비고 |
|---|---|---|---|
| 최소시간 | 거리 ÷ 제한속도 × 실시간 배율 × 돌발 배율 | 1차(기본) | |
| 무료도로 우선 | 소요시간 + 유료도로 링크 페널티 | 1차 | 한국도로공사 유료도로 노선을 링크에 태깅 |
| 최단거리 | 거리 | 내부용 | 테스트·검증 기준 |
| 최소요금 | 통행료(IC 진입~진출 쌍) | 2차 | 링크 단위가 아니라 IC쌍 단위 별도 모델링 필요 |
| 대안경로 | 최적 경로 핵심 링크에 페널티 후 재탐색(K-최단경로) | 2차 | 새 데이터 불필요 |

## 안전 정보 안내

일반 내비와 같은 수준으로, 실시간 예측이 아니라 **미리 저장된 데이터로 경고**한다.

- **과속카메라**: 점 안내. 구간단속은 시작·종료 쌍으로 묶어 구간 안내
- **과속방지턱**: 점 안내. 지자체 등록 편차가 있어 누락 가능성을 감수
- **사고다발지역**: 경로가 폴리곤을 지나면 경고(사망사고 건수 포함)
- **스쿨존**: 알림과 함께 해당 구간의 제한속도(30km/h)를 경로 계산에 직접 반영. 1차는 24시간 30km/h로 단순화(시간제 적용은 2026년 기준 전국 약 1만 5천여 곳 중 84곳, 다만 확대 중)

## 지도 화면

- 배경지도와 건물은 모두 **자체 지도서버**에 미리 적재해 서빙한다. 브이월드 타일은 쓰지 않는다.
- 1차는 2D(회전 포함, 주행 중 진행방향이 위로), 2차에 **2.5D**를 켠다: 두 손가락으로 쓸어올리면 같은 지도가 전환 효과 없이 연속으로 기울어지고 건물이 솟아 보인다. 실제 모바일 내비의 시점 변경과 같은 동작.
- 운영자는 관리 페이지에서 원본 데이터를 갱신하면 타일·도로망이 다시 만들어진다(2차).

## 스코프 제외 항목과 사유

| 항목 | 사유 |
|---|---|
| OSM 데이터 | 원칙상 미사용 — 한국에서는 지역별 품질 편차가 크고 국가 데이터가 있음 |
| 서울 TOPIS·경기 실시간 피드 | 국가교통정보센터가 통합 창구, 링크 체계가 달라 매칭 비용 큼. 운영 후 공백이 확인될 때만 재검토 |
| 대중교통·주차장·주유소 연계 | 차량 내비 핵심과 무관 |
| 기상특보 연동 | 이번 범위에서 불필요 |
| 실시간 블랙아이스 예측 | 공개 API 없음, 별도 ML 모델링 영역. 일반 내비처럼 저장된 사고다발 데이터로 경고하는 것으로 충분 |
| 차폭·차장 정밀 라우팅 | 표준노드링크에 폭 데이터 없음. 정밀도로지도(HD맵)로 가능하나 커버리지(고속국도·일반국도)와 처리 복잡도로 제외. 카카오모빌리티도 높이·중량·차종 수준까지만 지원 |
| 브이월드 3D(Cesium) | 주행 중 화면에는 무겁고, 2.5D로 충분 |
| 지도 렌더링 엔진 자체 개발 | 수십만 줄 규모. 오픈소스 MapLibre를 사용 |

## 도보·자전거 확장 계획 (OSM 미사용 전제)

- **자전거**: 행정안전부 전국 자전거길 표준데이터로 전국 커버 가능. 표준노드링크에서 자동차전용도로를 뺀 그래프 + 자전거길 레이어
- **도보 1단계**: 표준노드링크를 도보 그래프로 재활용(고속도로·자동차전용도로 제외, 일방통행 무시, 고정 속도). 전국 커버되지만 공원·지름길은 못 잡음
- **도보 2단계**: 국토지리정보원 수치지형도(1/5,000, 전국)에서 보행로·소로를 추출해 자체 보행 네트워크 구축. 도엽 병합·위상 정리가 필요한 큰 GIS 작업
- 로드맵에는 넣지 않고 남겨둔다. routedb는 가중치 있는 연결망이면 모두 다루므로 그래프를 모드별로 추가하는 방식으로 확장한다

## 향후 확장

- 최소요금 옵션, 대안경로 2~3개
- 스쿨존 시간제 속도제한 반영
- 2.5D 모드, 지도 갱신 관리 페이지, 자체 지오코더
- 도보·자전거 모드
- 정밀도로지도 기반 화물차 라우팅, 대중교통 연계, 블랙아이스 예측 모델(장기)
